# fhir_stub_server

A strict stub for the FHIR server and the validator used by FHIR test kits. It answers
only the requests a Scenario declares and reports everything else.

Work in progress; usage is documented once milestone 1 is complete.

## Development

```bash
bin/setup
bundle exec rake
```
